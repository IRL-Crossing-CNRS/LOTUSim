# How to contribute

Using LOTUSim or LOTUSim-Energy in your research? The BibTeX entries of both
papers are on the [home page](index.md#cite-lotusim).

## Contribute code

LOTUSim is split across repositories, and each has its own rules for
branches, commit messages and reviews. Read the guide of the repository you
are changing.
